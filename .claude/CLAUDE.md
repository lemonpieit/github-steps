# Project Instructions

## README Maintenance

Whenever you add, remove, or update an action implementation in this repository, you **must** update [README.md](../README.md) to reflect the change. This includes:

- Adding a new section for a new action (name, location/version tag, inputs table, behavior, example usage)
- Removing the section for a deleted action
- Updating any changed inputs, behavior, or example usage for a modified action

Keep the README structure consistent with existing sections (heading, location, inputs table, behavior bullets, example YAML snippets).
